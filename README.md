# Wordle

## Technologies Used
- HTML
- CSS
- JavaScript

## Description
A game where you guess a 5-letter word in 6 tries before the 60-second timer runs out.

## User Stories
1. As a User, I want to have 30 squares (5 columns and 6 rows) 
2. As a User, I want to have a secret word of 5 letters 
3. As a User, I want to have 6 attempts to guess the word
4. As a User, I want a keyboard to choose the letters
5. As a User, I want to see the squares change colors according to the accuracy
